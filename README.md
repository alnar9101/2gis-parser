# 2GIS Parser

Парсер организаций из 2ГИС на Python с использованием Selenium.

Проект предназначен для автоматизированного сбора информации об организациях Екатеринбурга и сохранения результатов в CSV.

## Возможности

- Поиск организаций по заданному запросу.
- Автоматическая прокрутка результатов поиска.
- Переход между страницами выдачи.
- Получение информации из карточек организаций.
- Проверка уникальности по ID организации в 2ГИС.
- Пропуск ранее сохранённых организаций.
- Сохранение каждой новой организации в CSV.

## Собираемые данные

- ID организации.
- Название.
- Адрес.
- Административный район.
- Микрорайон.
- Email (при наличии).
- Рубрика организации.

## Технологии

- Python
- Selenium WebDriver
- webdriver-manager
- CSV
- Git

## Установка

Клонировать репозиторий:

```bash
git clone https://github.com/alnar9101/2gis-parser.git
cd 2gis-parser
```

Создать и активировать виртуальное окружение:

```bash
python3 -m venv venv
source venv/bin/activate
```

Установить зависимости:

```bash
pip install -r requirements.txt
```

Для работы необходим совместимый браузер, настроенный в `browser.py`.

## Запуск

```bash
cd code
python main.py
```

Результаты сохраняются в CSV. Файлы CSV исключены из Git через `.gitignore`.
